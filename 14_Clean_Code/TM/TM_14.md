## Soal

Dari dua kode di bawah ini, mana yang kamu ingin cari masalahnya dan perbaiki di tengah-tengah malam, katakanlah jam 1 malam? Mengapa?

```
function processUser(user) {
  if (user) {
    if (user.isActive) {
      if (user.hasPermission) {
        return doSomething(user)
      }
    }
  }
  return null
}
```

```
function processUser(user) {
  if (!isValidCandidate(user)) return null;
  return doSomething(user);
}

function isValidCandidate(user) {
  return user && user.isActive && user.hasPermission;
}
```

## Deskripsi Program

Pada tugas mandiri modul 14 ini, saya akan memilih kode B atau kedua jika harus mencari masalah dan memperbaikinya pada jam 1 malam. Menurut saya, kode B lebih mudah untuk dibaca. Pada fungsi utama `processUser` tidak dipenuhi dengan `nested if` yang bertingkat. Kondisi pengecekan pada user sudah dipisahkan ke dalam fungsi `isValidCandidate`, sehingga alur programnya menjadi lebih jelas. Dibandingkan dengan kode A atau pertama, kode B lebih mudah karena logika validasinya terpisah dan dapat digunakan kembali.

Jadi, pilihan saya adalah `Kode B` karena lebih sederhana, lebih rapi, lebih mudah ketika debug, dan lebih aman dikerjakan ketika saya lelah pada jam 1 malam.
